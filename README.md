# Photo Layout Studio · 照片排版工作室

一个**纯前端、全本地运行**的照片排版工具：上传照片 → 选择纸张 → 自动排版 → 手动微调 → 高清导出 / 打印。

照片只在浏览器内存与本地存储中处理，不会上传到任何服务器。构建产物可静态托管，适合发布到 GitHub Pages。

---

## 1. 技术调研与选型

开发前对几类主流方案做了对比，最终选择「单一 Canvas 2D 渲染器 + DOM 交互层」的路线。

### 画布与交互

| 方案 | 优点 | 局限 | 结论 |
| --- | --- | --- | --- |
| **Konva / react-konva** | 自带场景图、事件命中、拖拽变换器 | 引入第二套渲染体系；导出时仍需重新绘制或 `toDataURL` 缩放失真；包体较大 | 未采用 |
| **Fabric.js** | 对象模型与序列化成熟 | 与 React 状态管理耦合别扭，毫米级纸张/DPI 控制需要绕开其坐标体系 | 未采用 |
| **DOM + CSS 变换** | 交互实现简单 | 无法直接输出高 DPI 位图，导出要依赖 html2canvas 二次渲染，所见非所得 | 未采用 |
| **Canvas 2D + DOM Overlay（采用）** | 预览与导出复用同一个 `renderPage`，像素级一致；毫米坐标直接可控；无额外渲染依赖 | 需要自己实现命中测试、旋转、吸附 | **采用** |

关键设计：画框数据（位置 / 尺寸 / 旋转 / 蒙版 / 裁切）是唯一数据源；Canvas 负责画面，DOM 只负责选中框、四角缩放手柄、旋转手柄与尺寸标签。因此**预览、PNG/JPEG 导出、PDF 内嵌图、打印都用同一套绘制代码**，不会出现「预览和成品不一致」。

### 导出与打印

| 方案 | 说明 | 结论 |
| --- | --- | --- |
| **jsPDF** | 常用，但页面尺寸以 pt/mm 设置时内部单位换算与图片嵌入需要较多手工处理 | 未采用 |
| **pdf-lib（采用）** | 纯 JS、无 DOM 依赖，可直接 `addPage([widthPt, heightPt])` 精确控制毫米尺寸，支持 JPEG 嵌入 | **采用** |
| **html2canvas + 浏览器打印** | 截图后打印易被缩放、丢失毫米精度 | 仅用于屏幕预览，不用于打印 |
| **隐藏 iframe + `@page`（采用）** | 用 `@page { size: 210mm 297mm; margin: 0 }` + 1:1 图片，交由系统打印，尺寸准确 | **采用** |

PDF 尺寸换算为 `mm / 25.4 * 72`，例如 A4 输出为 595.2756 × 841.8898 pt，与标准 A4 完全一致。

### 其他技术栈

| 领域 | 选择 | 理由 |
| --- | --- | --- |
| 构建 | **Vite 7** | 启动快、产物小，`base: './'` 即可部署到任意子路径 |
| 框架 | **React 19 + TypeScript** | 组件化面板/弹窗，类型约束画框与页面模型 |
| 样式 | **Tailwind CSS v4**（`@tailwindcss/vite`） | 无需额外配置文件，原子类快速搭建密集工具界面 |
| 状态 | **zustand 5** | 体量小、无 Provider 嵌套；方便实现命令式 store action 与撤销栈 |
| 持久化 | **idb-keyval**（IndexedDB）+ **localStorage** | 照片 Blob 存 IndexedDB（容量大），项目 JSON 存 localStorage（简单可靠） |
| 图标 | **lucide-react** | 线性图标风格统一 |
| 测试 | **Vitest** | 与 Vite 共用配置，直接测试排版算法与几何函数 |

### 单页 Canvas 而非每个画框一个 canvas

一个页面一个 canvas，全部画框按 `renderPage` 顺序绘制。这样导出时只需一次 `renderPageToCanvas(page, dpi)`；缩略图、取景预览、PDF 页面全部复用。DOM Overlay 只覆盖在选中画框上，成本极低。

## 2. 功能清单

### 照片与图库
- 拖拽 / 文件选择 / 粘贴式上传（JPG、PNG、WebP 等浏览器可解码格式）
- `createImageBitmap` 解码并遵循 EXIF 方向，失败时回退 `HTMLImageElement`
- 自动生成缩略图，列表展示尺寸与文件大小
- 内置 6 张程序化示例照片，可一键体验完整排版流程
- 照片持久化到 IndexedDB，刷新后自动恢复

### 纸张
- **36 种预设**：ISO A/B 系列、美式 Letter/Legal/Tabloid、R 系列相纸、方形相纸、全景、明信片、CR80 证件卡、身份证、护照、名片、拍立得、照片条、书签、CD 封面
- 每个预设支持横 / 竖方向切换，部分预设自带默认方向（如证件卡横版）
- 自定义毫米尺寸（10–2000 mm），自动判断横竖
- 页边距、画框间距、背景色、裁切线均可调

### 自动排版与模板
**自动排版**
- 智能网格：按纸张比例自动计算行列，照片裁切填满
- 等比联系表：不裁切照片，保持原始长宽比，货架算法 + 二分搜索求最大可用尺寸

**拼贴模板**
- 经典四宫格、九宫格、一大三小、上大下双、五格拼贴、三联画、双联画

**裁切与特殊工艺**
- 满版单图、拍立得白框（底部加宽留白）、四连拍照片条
- 证件照 1 寸（25 × 35 mm）/ 2 寸（35 × 49 mm），自动重复排满并开启裁切线
- **裁切四分**：一张照片切成 2 × 2，可剪下重组
- **错位切片**：竖条切片 + 上下错位，艺术拼贴效果
- 心形 / 圆形蒙版剪影、圆形三连
- **分页海报**：一张照片切成 2×2 ~ 8×8 张纸，生成多页 PDF，打印后拼接成大幅海报

模板缩略图按当前纸张真实比例渲染，照片不足时自动循环复用图库图片。

### 手动局部调整
- 单击选中、拖动移动、四角缩放、上方圆形手柄旋转（全部按旋转后的局部坐标计算）
- 双击进入**取景调焦**：拖动照片改变构图，滚轮缩放，Esc / 双击空白退出
- 右侧属性检查器：
  - 构图模式 `cover` / `contain` / `stretch`，缩放与焦点
  - 蒙版形状：矩形 / 圆角 / 圆形 / 拱形 / 心形 / 六边形
  - 圆角半径、旋转角度、边框宽度与颜色
  - 卡纸留白、底部额外留白（拍立得效果）、卡纸颜色、投影、不透明度
  - X/Y/宽/高数值输入、六向对齐、图层上移下移置顶置底、锁定画框
- 拖动吸附：页面边缘、页边距、其他画框、页面中心；按住 Shift 临时关闭
- 有效 DPI 提示：低于 150 DPI 的照片在导出前以琥珀色标记
- 撤销 / 重做：40 步历史，同类连续操作（拖动、缩放）1.2 秒内合并为一步

### 多页与导出
- 页面新增 / 复制 / 删除 / 切换，缩略图导航
- 导出 **PDF**（多页、毫米精确）、**PNG / JPEG**（当前页）、**浏览器打印**
- DPI 150 / 300 / 600 可选，实时估算输出像素尺寸
- 导出安全上限：单边 16000 px、总像素约 6000 万；超限自动降 DPI 并提示
- 自动保存：项目 JSON 防抖 500 ms 写入 localStorage

## 4. 架构

```
src/
├─ App.tsx                  # 布局组合：顶栏 / 左面板 / 画布 / 页面条 / 右检查器 / 弹窗
├─ main.tsx
├─ index.css                # Tailwind v4 + UI 原子类
├─ types.ts                 # Frame / Page / Project / PaperPreset 等领域模型
├─ data/
│  ├─ papers.ts             # 36 种纸张预设与方向换算
│  └─ templates.ts          # 19 个模板定义 + 归一化预览格子
├─ lib/
│  ├─ layout.ts             # 全部排版算法（网格 / 货架 / 拼贴 / 证件照 / 切片 / 海报）
│  ├─ geometry.ts           # 旋转坐标、命中测试、AABB、cover 裁切、吸附、有效 DPI
│  ├─ render.ts             # 唯一渲染器：shapePath / drawPhoto / drawFrame / renderPage
│  ├─ export.ts             # PNG / JPEG / PDF / 浏览器打印 + 导出尺寸安全限制
│  ├─ image.ts              # 解码、缩略图、缓存、示例照片生成
│  └─ persist.ts            # IndexedDB 照片 + localStorage 项目
├─ store/
│  └─ store.ts              # zustand store、命令式 action、撤销栈、自动保存订阅
└─ components/              # TopBar / LeftPanel / CanvasView / Inspector / 各类弹窗
```

### 数据流

```
上传 → importPhotoBlob → image.ts 解码缓存 + persist.ts 写入 IndexedDB
                                              ↓
模板 → layout.ts 生成 Frame[] → store.commit()（记录历史）
                                              ↓
CanvasView: 预览坐标(px) ⇄ 版面坐标(mm)  → renderPage() 绘制
                                              ↓
导出: renderPageToCanvas(page, DPI) → PNG/JPEG，或 pdf-lib 嵌入 → PDF
```

### 坐标系约定

- **版面坐标**：毫米，原点为纸张左上角，`Frame.x/y` 是未旋转时的左上角。
- **画框局部坐标**：原点为画框中心，旋转后仍保持稳定，用于命中测试与裁剪。
- **屏幕坐标**：预览用 `scale = fitScale * zoom` 与 `originX/originY` 映射，只存在于 CanvasView。

`pageToLocal` / `localToPage` 会先减去画框中心偏移再旋转，这是旋转画框命中测试正确的前提。

## 5. 本地开发

```bash
npm install
npm run dev        # 开发服务器
npm run typecheck  # TypeScript 检查
npm test           # Vitest：排版算法 / 几何 / 导出尺寸
npm run build      # 生产构建，输出 dist/
npm run preview    # 预览构建产物
```

Node 建议 ≥ 20。测试覆盖排版算法（网格、联系表、拼贴、证件照、切片、海报）、几何（旋转往返、命中、吸附、DPI）与导出尺寸限制，共 26 个用例。

## 6. 部署到 GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`：

1. 把项目推送到 GitHub 仓库的 `main` 分支。
2. 打开 **Settings → Pages**，Source 选择 **GitHub Actions**。
3. 之后每次推送 `main` 都会自动执行 `typecheck → test → build → deploy`。
4. 构建使用 `base: './'`（见 `vite.config.ts`），因此**不需要**为仓库子路径额外配置，`https://<user>.github.io/<repo>/` 可直接访问。

如需手动部署，也可把 `dist/` 目录内容上传到任意静态托管（Netlify、Cloudflare Pages、对象存储等）。

## 7. 打印须知

- **尺寸精确**：PDF 页面尺寸与所选纸张完全一致（mm → pt），照片冲印店或 PDF 打印可直接按实际尺寸输出。
- **浏览器打印**：会通过隐藏 iframe 输出 1:1 毫米页面。请在系统打印对话框中选择**相同纸张**，并把「缩放」设为 **100% / 实际尺寸**，关闭「适应页面」。
- **DPI 建议**：照片类 300 DPI，证件照 / 明信片使用无边距照片纸；A4 拼版可增大页边距，避免落入打印机不可打印区域。
- **裁切线**：证件照、裁切四分等模板会自动开启裁切线；导出弹窗中可再单独控制是否把裁切线渲染进文件。
- **分页海报**：导出「全部页」得到多页 PDF，按页码顺序打印后裁掉白边拼接；拼接处建议预留 2–3 mm 重叠。

## 8. 已知限制

- 打印精度最终取决于打印机与系统驱动，浏览器无法控制硬件边距。
- 处理超大照片（如 8000 万像素）时内存占用较高，导出会自动降低 DPI。
- 移动端采用固定三栏布局，小屏设备仅画布区域可用，暂未提供精简移动布局。
- 项目数据保存在当前浏览器，更换浏览器 / 清除站点数据后需重新导入照片。

---

## 9. 隐私

所有照片解码、排版、导出均在浏览器内完成；IndexedDB 与 localStorage 仅存储在本机。应用不包含任何上传接口与第三方统计。
